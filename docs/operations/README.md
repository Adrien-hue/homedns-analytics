# Operations

This directory contains the operational documentation for HomeDNS.

## Documents

-   installation.md --- Prepare a new Raspberry Pi.
-   deployment.md --- Build, deploy and validate releases.
-   service-management.md --- Operate the systemd service.
-   benchmarking.md --- Execute and analyze benchmarks.
-   releases.md --- Release lifecycle and versioning.
-   troubleshooting.md --- Diagnose common issues.
-   maintenance.md --- Routine maintenance tasks.
