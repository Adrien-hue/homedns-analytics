# Releases

Each release contains:

-   Release ID
-   Version
-   Commit SHA
-   Build timestamp

Workflow:

    feature
       ↓
    develop
       ↓
    benchmark
       ↓
    release
       ↓
    tag
       ↓
    main

Versioning follows Semantic Versioning:

-   v0.2.0
-   v0.2.1
-   v0.3.0
-   v1.0.0
